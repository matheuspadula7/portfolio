# Estudos de Python

Pasta de prática do curso de Segurança da Informação (Lógica de Programação e Algoritmos).
O guia dos exercícios fica no Lab: https://matheuspadula.com.br/lab/

## Como usar

1. Abra esta pasta no VS Code (`Arquivo > Abrir Pasta`).
2. Escolha um exercício no Lab e abra o arquivo indicado (por exemplo `ex_2_1.py`).
3. Escreva a solução e rode no terminal do VS Code (`Ctrl+'`):
   ```
   py ex_2_1.py
   ```
4. Confira com os mesmos testes do Lab:
   ```
   py conferir.py ex_2_1.py
   ```
   Sem argumento, `py conferir.py` confere todos os arquivos de uma vez.
5. Quando passar, marque como feito no Lab.

Arquivos `exp_*.py` são experimentos: rode, observe e leia a explicação no Lab.
